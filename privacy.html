Privacy policy

Zoneline · Effective 14 November 2026

Summary

Zoneline does not collect, transmit or share any personal data. It has no analytics, no advertising and no crash reporting service. Its only network use is downloading the public market-hours file described below, which you can turn off.

What the app stores on your PC

  • Settings: your clocks and timelines (time zone, region name, position, size, style, theme, opacity, always-on-top), your reminders (title, note, time zone, times, repeat, notification choice) and the UI language, in a config.json file in the app's own data folder. When installed from the Microsoft Store this is the app's package folder under %LOCALAPPDATA%\Packages.
  • Custom themes: only if you create or add one, in Documents\Zoneline\Themes.
  • Error log: if the app hits an unexpected error, a technical description is appended to error.log in the same data folder. It never leaves your PC.

These files stay on your computer. Uninstalling the Store app removes its data folder; custom themes in Documents are yours to keep or delete.

What the app reads

Reminder notifications are shown by Windows on this PC; nothing about them is sent anywhere. Time zone rules come from Windows. The app reads its own settings and theme files. It does not read your documents, browsing data or other apps' data.

Market hours updates

To keep exchange holidays and trading hours current, the app downloads one public file, https://zoneline.coldlapse.dev/data/markets-v1.json, about once a day and when you press "Check now" in Settings → Markets. The request contains no account, identifier, cookie or information about your clocks, reminders or markets; it carries the app's name and version. Like any web request, it reaches GitHub Pages, which hosts the file and may keep standard server logs (such as IP addresses) under its own policy. Turn it off with "Update market hours automatically" in Settings → Markets; the app then uses the market data it was installed with.

Links

The "Website" and "Theme guide" buttons open this website in your default browser. Your browser, not the app, makes that connection. This website is hosted on GitHub Pages and loads a font from jsDelivr; those services may keep standard server logs (such as IP addresses) under their own policies. The website sets no cookies; it remembers your language choice in your browser's local storage.

Purchases

The app is sold through the Microsoft Store. Payment and licensing are handled entirely by Microsoft under the Microsoft Privacy Statement. The developer does not receive your payment details.

Children

The app collects no data from anyone, including children.

Changes

If this policy changes, the new version will be posted on this page with a new effective date.

개인정보 처리방침

Zoneline · 시행일 2026년 11월 14일

요약

Zoneline은 개인정보를 수집하거나 전송하거나 공유하지 않습니다. 분석 도구, 광고, 오류 보고 서비스가 없습니다. 네트워크는 아래에 적은 공개 장 시간 파일을 내려받을 때만 쓰며, 이 기능은 끌 수 있습니다.

앱이 내 PC에 저장하는 것

  • 설정: 시계와 타임라인 목록(시간대, 지역명, 위치, 크기, 표시 방식, 테마, 불투명도, 항상 위), 알림(제목, 메모, 시간대, 시각, 반복, 알림 방식), UI 언어를 앱 데이터 폴더의 config.json에 저장합니다. Microsoft Store에서 설치했다면 %LOCALAPPDATA%\Packages 아래 앱 패키지 폴더입니다.
  • 사용자 테마: 직접 만들거나 추가한 경우에만 문서\Zoneline\Themes에 있습니다.
  • 오류 기록: 예상하지 못한 오류가 나면 기술적인 내용을 같은 데이터 폴더의 error.log에 덧붙입니다. PC 밖으로 나가지 않습니다.

이 파일들은 내 컴퓨터에만 있습니다. Store 앱을 제거하면 데이터 폴더도 지워지고, 문서 폴더의 사용자 테마는 직접 보관하거나 지우면 됩니다.

앱이 읽는 것

알림은 이 PC에서 Windows가 표시하며, 그 내용은 어디로도 보내지 않습니다. 시간대 규칙은 Windows에서 가져옵니다. 앱은 자신의 설정 파일과 테마 파일만 읽습니다. 문서, 브라우저 기록, 다른 앱의 데이터는 읽지 않습니다.

장 시간 업데이트

거래소 휴장일과 거래 시간을 최신으로 유지하려고, 앱은 공개 파일 하나(https://zoneline.coldlapse.dev/data/markets-v1.json)를 하루에 한 번쯤, 그리고 설정 → 시장에서 "지금 확인"을 누를 때 내려받습니다. 요청에는 계정, 식별자, 쿠키, 내 시계나 알림이나 시장에 관한 정보가 들어 있지 않고, 앱 이름과 버전만 담깁니다. 여느 웹 요청처럼 파일을 호스팅하는 GitHub Pages에 도달하며, GitHub Pages는 자체 정책에 따라 일반적인 서버 기록(IP 주소 등)을 남길 수 있습니다. 설정 → 시장의 "장 시간 자동 업데이트"를 끄면 내려받지 않고, 설치할 때 들어 있던 장 데이터를 씁니다.

링크

"웹사이트"와 "테마 제작 가이드" 버튼은 기본 브라우저로 이 사이트를 엽니다. 연결은 앱이 아니라 브라우저가 합니다. 이 사이트는 GitHub Pages에서 제공되고 jsDelivr에서 글꼴을 불러오며, 두 서비스는 각자의 정책에 따라 일반적인 서버 기록(IP 주소 등)을 남길 수 있습니다. 사이트는 쿠키를 쓰지 않고, 고른 언어만 브라우저의 로컬 저장소에 기억합니다.
