Theme guide

Theme format version 1

A theme is a folder with a theme.json file and, optionally, images and fonts. It controls everything a clock draws: the card behind it, the digital and analog faces, the hands, ticks and numbers, and the region-name and UTC-offset labels.

Quick start

  1. Open Settings → Themes → New theme from template. This creates Documents\World Clock Gadget\Themes\my-theme\ and selects its theme.json in Explorer.
  2. Open theme.json in any text editor (Notepad, VS Code).
  3. Right-click a clock → Theme → My Theme (Custom).
  4. Edit and save. The clock redraws as soon as the file is saved. Errors appear under the theme's card in Settings → Themes.

The template lists every setting with its default value and a comment. Delete what you don't need: anything missing keeps its default. The smallest useful theme is a few lines:

{
  "name": "Orange",
  "digital": { "font": { "color": "#FF8800" } },
  "labels":  { "name": { "color": "#FF8800" } }
}

File rules

  • File name theme.json, UTF-8. Comments (//, /* */) and trailing commas are allowed. Key names are case-insensitive.
  • The folder name is the theme's id. Rename the folder and clocks using it fall back to the default theme.
  • Folders whose names start with _ or . are ignored (handy for drafts).
  • Images and fonts are looked up relative to the theme folder. Paths that leave the folder (../) are ignored.
  • Unknown keys are ignored, so a theme written for a newer version still loads.

Bundling a font

Put the .ttf or .otf next to theme.json, set file to its name and family to the font's family name (the name Windows shows when you open the font file), not the file name. Check the font's licence before sharing a theme that bundles it.

"font": { "file": "Orbitron-Bold.ttf", "family": "Orbitron", "size": 36 }

Image hands

A hand can be a picture instead of a line. Draw it pointing straight up (12 o'clock) on a transparent background, then:

"minuteHand": { "image": "minute.png", "length": 0.8, "tail": 0.15, "pivotX": 0.5, "pivotY": 0.84 }

The picture is scaled so its height equals length + tail times the dial radius. pivotX and pivotY mark the point it rotates around, as fractions of the image's width and height (here: centred horizontally, 84% of the way down).

timeline: the timeline gadget

A vertical axis of this PC's local time: the recent past above the now line, the future below it. Each timeline gadget chooses its own range (how many hours back and ahead) and length; the theme decides how it looks. The card (gadget) and shadow are shared with the clocks.

Labels never overlap: when reminders are close together, the labels stack and a leader line points back to the moment. Labels that do not fit are counted at the bottom ("+3").

Sharing a theme

Zip the theme folder. The person you send it to unzips it into Documents\World Clock Gadget\Themes\ (Settings → Themes → Open themes folder). Only include images and fonts you are allowed to share.

Troubleshooting

  • The clock uses the default look. The theme failed to load. The error, with line and column, is shown under the theme in Settings → Themes.
  • A colour or image does not show. Settings → Themes lists warnings for colours that cannot be read and files that are missing.
  • My font is ignored. family must be the font's family name, not the file name. Windows falls back to the next family in the list.
  • Changes don't appear. Make sure you saved the file. If your editor saves somewhere unusual, press Reload in Settings → Themes.

테마 제작 가이드

테마 형식 버전 1

테마는 theme.json 파일 하나와, 필요하면 이미지와 글꼴을 담은 폴더입니다. 시계가 그리는 모든 것을 테마가 정합니다. 뒤의 카드, 디지털·아날로그 문자판, 바늘과 눈금과 숫자, 지역명과 UTC 표기 라벨까지요.

빠르게 시작하기

  1. 설정 → 테마 → 템플릿으로 새 테마를 누릅니다. 문서\World Clock Gadget\Themes\my-theme\ 폴더가 생기고 탐색기에서 theme.json이 선택됩니다.
  2. theme.json을 아무 텍스트 편집기(메모장, VS Code)로 엽니다.
  3. 시계를 오른쪽 클릭 → 테마 → My Theme (사용자)를 고릅니다.
  4. 고치고 저장합니다. 저장하는 즉시 시계가 다시 그려집니다. 오류는 설정 → 테마의 해당 테마 아래에 나옵니다.

템플릿에는 모든 설정이 기본값, 설명과 함께 들어 있습니다. 필요 없는 줄은 지워도 됩니다. 빠진 설정은 기본값을 씁니다. 그래서 몇 줄짜리 테마도 됩니다.

{
  "name": "Orange",
  "digital": { "font": { "color": "#FF8800" } },
  "labels":  { "name": { "color": "#FF8800" } }
}

파일 규칙

  • 파일 이름은 theme.json, UTF-8입니다. 주석(//, /* */)과 끝 쉼표를 써도 됩니다. 키 이름은 대소문자를 가리지 않습니다.
  • 폴더 이름이 테마 ID입니다. 폴더 이름을 바꾸면 그 테마를 쓰던 시계는 기본 테마로 돌아갑니다.
  • 이름이 _나 .로 시작하는 폴더는 무시합니다(초안 보관용).
  • 이미지와 글꼴은 테마 폴더 기준 상대 경로로 찾습니다. 폴더 밖을 가리키는 경로(../)는 무시합니다.
  • 모르는 키는 무시하므로, 새 버전용으로 만든 테마도 불러올 수 있습니다.

글꼴 함께 넣기

.ttf나 .otf를 theme.json 옆에 두고, file에는 파일 이름을, family에는 글꼴의 패밀리 이름(글꼴 파일을 열면 Windows가 보여 주는 이름)을 씁니다. 파일 이름이 아닙니다. 글꼴을 넣은 테마를 공유하기 전에 글꼴 라이선스를 확인하세요.

이미지 바늘

바늘을 선 대신 그림으로 그릴 수 있습니다. 투명 배경에 12시 방향(위쪽)을 가리키도록 그린 뒤 이렇게 씁니다.

"minuteHand": { "image": "minute.png", "length": 0.8, "tail": 0.15, "pivotX": 0.5, "pivotY": 0.84 }

그림의 높이가 문자판 반지름 × (length + tail)이 되도록 늘리고 줄입니다. pivotX, pivotY는 회전 중심을 그림의 너비와 높이에 대한 비율로 나타냅니다(위 예는 가로 가운데, 위에서 84% 지점).

테마 공유하기

테마 폴더를 zip으로 묶어 보내면, 받는 사람이 문서\World Clock Gadget\Themes\(설정 → 테마 → 테마 폴더 열기)에 풀면 됩니다. 공유해도 되는 이미지와 글꼴만 넣으세요.

문제 해결

  • 시계가 기본 모양으로 나와요. 테마를 불러오지 못한 것입니다. 설정 → 테마의 해당 테마 아래에 오류와 줄·열 번호가 나옵니다.
  • 색이나 이미지가 안 보여요. 읽을 수 없는 색과 없는 파일은 설정 → 테마에 경고로 나옵니다.
  • 글꼴이 적용되지 않아요. family는 파일 이름이 아니라 글꼴의 패밀리 이름이어야 합니다. 못 찾으면 목록의 다음 글꼴을 씁니다.
  • 바꾼 내용이 안 보여요. 파일을 저장했는지 확인하세요. 편집기가 특이한 방식으로 저장한다면 설정 → 테마에서 다시 불러오기를 누르세요.
